# Lab3 — лінійна регресія для акумулятора

Ноутбук оцінює стан заряду літій-іонного акумулятора за експериментальною OCV–SOC кривою.

## Набір даних

Вихідне джерело містить 1001 вимір напруги розімкнутого кола та стану заряду. Для компактної роботи використано 501 рівномірно розподілене спостереження (крок SOC 0.002). `battery_soc.csv` містить три ознаки напруги: OCV, OCV², OCV³, і ціль SOC у відсотках; `battery_soc_curve_source.csv` — повна крива з джерела.

Джерело: [Zenodo record 10.5281/zenodo.6985321](https://zenodo.org/records/6985321), експериментальна OCV–SOC крива

## Запуск

У VS Code оберіть наявний kernel проєкту `.venv`, відкрийте `Lab3_Люлько.ipynb` і виконайте **Restart Kernel and Run All Cells**. Потрібні залежності: NumPy, pandas, Matplotlib, scikit-learn та Jupyter.

Підсумкові `metrics.csv`, `test_predictions.csv` і три PNG-графіки збережені в цій папці.

# Лабораторна робота № 9 — CNN для Food-101

**Номер у списку:** 17. **Індекси класів:** 16, 46, 76 (нумерація з нуля), тобто `cheese_plate`, `garlic_bread`, `pizza`. Під час запуску назви звіряються з `meta/classes.txt` офіційного набору; порядок відповідає міткам 0, 1, 2.

Мета — навчити власну CNN для трьох класів, порівняти базову модель із Dropout 0.3 за validation та один раз оцінити обрану модель на офіційному test. Ноутбук: [Lab9.ipynb](Lab9.ipynb).

## Дані та запуск

1. Архів [Food-101](https://data.vision.ee.ethz.ch/cvl/datasets_extra/food-101/) уже додано локально як `food-101.zip`. Із нього розпаковано метадані та 3000 фото потрібних класів до `datasets/food-101/`. Для запуску в іншому середовищі потрібна папка `food-101`, у якій є `images/` та `meta/classes.txt`, `meta/train.txt`, `meta/test.txt`. Не додавайте архів чи зображення до Git.
2. Виберіть наявний інтерпретатор `Lab5/.venv/bin/python` як Jupyter-ядро. У ньому перевірено Python 3.9.6 і TensorFlow 2.16.2. У першій кодовій клітинці за потреби змініть `FOOD_ROOT` або задайте змінну середовища; локальна підмножина вже лежить за шляхом, який використовується за замовчуванням. Нове `.venv` не створюйте.
3. Виконайте **Run All** у `Lab9.ipynb`. Поділ із seed 42 створить `data/food101_lab9/{train,val,test}`, `manifest.json`, а далі ноутбук запише результати, графіки, `class_names.json` і локальну модель `food_cnn.keras`.
4. Крок 12 уже демонструє прогноз на зовнішньому фото піци. Для прогнозу іншого фото змініть `OWN_PHOTO` у відповідній клітинці та повторно виконайте її. Фото має належати до одного з трьох вибраних класів.

Джерельний train містить по 750 фото на клас: 600 для навчання й 150 для validation; офіційний test містить по 250. Код перевіряє списки файлів, відсутність перетинів, SHA-256 і читання JPEG. `manifest.json` і `results/` генеруються після реального запуску та можуть бути додані до Git. Дані й модель виключені з Git.

## Стан

Архів доступний локально. Для `cheese_plate`, `garlic_bread` і `pizza` виконано поділ 600/150/250 на клас; створено `manifest.json`. Усі 3000 зображень прочитано, копії звірено з джерелом, перетинів ID і точних SHA-256-дублікатів між частинами не виявлено. Зразки train-зображень збережено в `results/data_samples.png`.

Для навчання використано наявне сумісне середовище `Lab5/.venv` (Python 3.9.6, TensorFlow 2.16.2, CPU). Ноутбук виконано послідовно; результати збережено у `results/`, модель — локально у `food_cnn.keras`.

## Результати виконання

| Конфігурація | Епохи | Найкраща епоха | Час, с | Validation loss | Validation accuracy |
| --- | ---: | ---: | ---: | ---: | ---: |
| Базова CNN | 30 | 30 | 329,17 | 0,6878 | 0,7089 |
| Dropout 0.3 | 30 | 30 | 312,81 | **0,6813** | 0,6978 |

За нижчим validation loss обрано **Dropout 0.3**. На незалежних 750 test-фото отримано accuracy **0,7507** та macro-F1 **0,7493**; accuracy класифікатора найчастішого класу — **0,3333**. Recall становить 0,776 для `cheese_plate`, 0,644 для `garlic_bread` і 0,832 для `pizza`.

Найслабший клас — `garlic_bread`: 49 його фото передбачено як `cheese_plate`, ще 40 — як `pizza`. Серед `cheese_plate` 43 фото передбачено як `garlic_bread`; на одному прикладі хлібці займають значну частину тарілки із сиром. Зображення різняться фоном і ракурсом, а train-мітки Food-101 можуть бути шумними. Криві train і validation loss загалом спадали до 30-ї епохи, тому межа епох могла зупинити подальше покращення. Перевага Dropout за validation loss мала (0,0065) і встановлена на одному seed; за validation accuracy базова модель була кращою.
